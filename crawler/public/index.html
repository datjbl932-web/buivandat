Tài liệu API

      
Gọi giống Crawlbase Crawling API: chỉ cần đổi địa chỉ máy chủ. Thêm scraper= để nhận JSON đã phân tích.

      
Crawl một URL

      

      
Tham sốÝ nghĩa

        
tokenAPI token (hoặc header Authorization: Bearer …)

        
urlURL cần crawl (nhớ mã hoá URL)

        
scraper

        
formathtml (mặc định khi không có scraper) hoặc json

        
cachefalse để luôn tải mới

        
retriesSố lần thử lại khi bị chặn (0–8)

        
javascripttrue để mở bằng trình duyệt thật (máy chủ cần bật ENABLE_JS)
